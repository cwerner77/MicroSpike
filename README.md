# µSpike
An analog spiking neural network (SNN) experiment board with digital control

## Purpose
A powerful and flexible experimental board for exploring SNN technology. This project is primarily aimed at lecturers, students, and researchers at universities.

## Project parts
- Electronics: Schematics and PCB design
- Microcontroller programs usable with https://www.pjrc.com/store/teensy41.html and 
- Circuit simulation usable with https://www.falstad.com/circuit/

## Prerequisites
- Basic knowledge on how SNN work
- Basic skills in hardware-level computer engineering: setting up microcontrollers and attaching sensors as needed
- Basic skills in electrical engineering: use a graphical circuit simulation tool for designing a SNN circuit from predefined building blocks

## Typical workflow
1. Design your SNN in simulation environment
2. Build µSpike board and flash µSpike control software
3. Configure µSpike to your application's needs using the µSpike control software
4. Do your experiments and enjoy µSpike control software's powerful logging features
